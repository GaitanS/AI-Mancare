#### 2. Structured Data (Schema.org)

**Organization Schema (Homepage)**
```json
{
  "@context": "https://schema.org",
  "@type": "Organization",
  "name": "CatalogSmart",
  "url": "https://catalogsmart.ro",
  "logo": "https://catalogsmart.ro/logo.png",
  "description": "Cataloage online Kaufland, Lidl, Profi cu oferte si reduceri"
}
```

**WebSite Schema (Homepage)**
```json
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "CatalogSmart",
  "url": "https://catalogsmart.ro",
  "potentialAction": {
    "@type": "SearchAction",
    "target": "https://catalogsmart.ro/oferte?search={search_term_string}",
    "query-input": "required name=search_term_string"
  }
}
```

**OfferCatalog Schema (Catalog Pages)**
```json
{
  "@context": "https://schema.org",
  "@type": "OfferCatalog",
  "name": "Catalog Kaufland 19 Februarie 2025",
  "description": "Catalog Kaufland valabil saptamana 19-25 Februarie 2025",
  "validFrom": "2025-02-19",
  "validThrough": "2025-02-25",
  "url": "https://catalogsmart.ro/catalog-kaufland-19-februarie-2025"
}
```

**Recipe Schema (Recipe Pages)**
```json
{
  "@context": "https://schema.org",
  "@type": "Recipe",
  "name": "{Recipe Name}",
  "image": "{Recipe Image}",
  "description": "{Description}",
  "recipeIngredient": [...],
  "recipeInstructions": [...],
  "totalTime": "PT30M",
  "recipeYield": "4 servings"
}
```
